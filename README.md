# 💰 Expense Tracker System

This is a simple Python-based Expense Tracker application that helps users manage their daily expenses efficiently. The program is menu-driven and uses CSV file handling to store and retrieve data.

## 🚀 Features
- Add daily expenses (Date, Category, Amount)
- View all recorded expenses
- Calculate total spending
- Search expenses by category
- Data stored in CSV file (expenses.csv)

## 🛠️ Technologies Used
- Python (Core Concepts)
- File Handling
- CSV Module
- Loops and Conditional Statements
- Exception Handling

## 📂 How It Works
The program runs in a loop and displays a menu where users can select different options. All expense data is stored in a CSV file, making it easy to manage and retrieve.

## 🎯 Purpose
This project is designed for beginners to practice Python fundamentals and build a real-world mini application.
